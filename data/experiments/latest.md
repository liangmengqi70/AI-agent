# 对照实验结果

- **Agent 组**：每轮复盘后采纳全部建议；**固定策略组**：全部不采纳，始终使用策略 v1；
- 两组共用同一个模拟器随机种子（同一岗位的结果相同），都投递推荐页上的全部岗位；
- 每轮统计投递满 7 天时的结果：邀请率 = 收到笔试或面试邀请 / 已回复，面试率 = 收到面试 / 投递数。
